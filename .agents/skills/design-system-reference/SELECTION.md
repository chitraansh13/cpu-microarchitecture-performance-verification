# Design System Selection

- **Selected Reference**: Vercel-Inspired Design Language (`design-md/vercel/DESIGN.md`)
- **Source URL**: `https://raw.githubusercontent.com/VoltAgent/awesome-design-md/main/design-md/vercel/DESIGN.md`

## Rationale for Selection

1. **High Visual Restraint**: Uses cold neutral/graphite surfaces with crisp hairline borders (`#1d283a` / `#ebebeb`), avoiding unnecessary visual noise or decorative fluff.
2. **Data-Dense Technical Layouts**: Perfect for hardware engineering consoles requiring compact tables, key-value parameter pairs, and high-density metrics grids.
3. **Typography Pairings**: Employs clean geometric sans-serif for UI navigation and controls paired with crisp monospace (`Geist Mono`, `ui-monospace`) for instruction traces, memory addresses, and simulation status logs.
4. **Restrained Color Accents**: Focuses on neutral canvas surfaces with semantic status accents (emerald green for PASS, red for FAIL, amber for warning/fault injection, cyan for live execution badges).

## Borrowed Principles

- Compact table cell padding and hairline row dividers.
- Monospace captions for technical parameters and register bitfields (`[3:2] index`, `[15:4] tag`).
- Dark-first graphite surfaces (`#070a11` background, `#0f1623` card surfaces, `#1d283a` subtle borders).
- High-contrast, compact status pill badges.

## Elements Excluded

- Vercel logos, triangle icons, and trademarks.
- Proprietary Vercel marketing copy or product names.
- Multi-color marketing mesh gradients.
